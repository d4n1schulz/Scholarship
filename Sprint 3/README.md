# Resumo

**Elementos técnicos essenciais da AWS:** No curso de Elementos técnicos essenciais da AWS aprendi sobre IAM (gerenciamento de acesso e identidade), EC2 (computação escalável na nuvem), S3 (armazenamento de objetos), VPC (rede virtual isolada) e Lambda (execução de código sem servidor). Essas ferramentas são a base para construir e gerenciar aplicações robustas e escaláveis. 

**AWS Partner Credenciamento:** O curso AWS Partner Credenciamento aprendi sobre os conceitos fundamentais da AWS, benefícios do programa de parceiros, melhores práticas para vender soluções na nuvem e como alavancar recursos da AWS para atender clientes. Ideal para fortalecer parcerias e impulsionar negócios.

**Docker:** No curso sobre Docker, tive a oportunidade de aprender a criar, configurar e gerenciar containers, que são ambientes isolados para executar aplicações. Entendi conceitos como imagens, volumes e redes, além de utilizar o Dockerfile para personalizar ambientes. Além disso, criei e executei meu primeiro container com sucesso. 

**REGEX:** No vídeo sobre Regex, aprendi a utilizar expressões regulares para buscar, validar e manipular padrões em textos de forma eficiente.
