# Resumo

**Python:** No curso de Python eu consegui aprender a elaborar códigos eficientes e aprender toda a lógica de programação com essa linguagem, o que me ajudou muito, pois eu tinha quase nenhuma prática com Python, então praticamente todo o curso eu aprendi do zero, agora tenho capacidade de manipular arquivos e fazer operações com as estruturas de dados presentes na linguagem.
