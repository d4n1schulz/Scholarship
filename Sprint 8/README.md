# Resumo

**Complete Introduction to Amazon QuickSight**: Aprendi a usar o AWS QuickSight para criar análises e relatórios visuais eficientes, desde o carregamento e preparação de dados até a aplicação de cálculos, filtros e visualizações avançadas. Explorei técnicas como cálculos de tabela (porcentagens, rankings) e criação de KPIs, além de aprender a compartilhar dashboards interativos. O curso destacou a integração de múltiplas fontes de dados e o uso do SPICE para análises rápidas e escaláveis.

**Amazon QuickSight - Getting Started**: Este curso introdutório sobre Amazon QuickSight ensina os conceitos básicos, arquitetura e benefícios dessa ferramenta de BI em nuvem, incluindo casos de uso e estrutura de custos. Através de demonstrações, aprendi a criar e personalizar análises e dashboards, além de publicar visualizações interativas. O treinamento é voltado para analistas de dados e desenvolvedores de BI, com foco em extrair insights de forma rápida e escalável.
